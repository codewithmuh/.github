# Default Community Health & Governance Files (.github)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository serves as the **account-wide default community health repository** for [`@codewithmuh`](https://github.com/codewithmuh).

According to [GitHub's Community Health Documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file), any public repository owned by `@codewithmuh` that does not define its own community files automatically inherits these centralized standards:

---

## Centralized Standards

| Document | Purpose & Standard |
| :--- | :--- |
| [**Issue Templates**](.github/ISSUE_TEMPLATE/) | Structured GitHub Issue forms for bug reporting and enhancement proposals |
| [**PR Template**](.github/PULL_REQUEST_TEMPLATE.md) | Pre-flight quality, security, and testing checklist for pull requests |
